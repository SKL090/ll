# 🎭 Шариковая Жизнь (Ball Life)

2D-симуляция средневекового городка, где ты — **серый кардинал**: молчаливый наблюдатель, который дёргает за ниточки. NPC — актёры твоей пьесы: они видят друг друга, ходят по городу, торгуют, дружат, ненавидят, а иногда — поджигают и убивают.

## 🎮 Управление

| Клавиша / мышь | Действие |
|----------------|----------|
| **ЛКМ по NPC** | Панель «ниточек» (шёпот + приказы) |
| **ЛКМ по пустому месту** | Снять выбор |
| **ПКМ** | Пауза |
| **WASD / стрелки** | Двигать камеру |
| **Колесо мыши** | Зум |
| **Средняя кнопка + тянуть** | Панорамирование |
| **M** | Карта отношений |
| **F** | Поджечь тайл под курсором |
| **F5 / F6** | Сохранить / загрузить |
| **R** | Новая игра |
| **ESC** | Закрыть панель / пауза |

## 🧵 Серый кардинал

Клик по NPC открывает панель с двумя блоками:

**Ниточки (шёпот)** — косвенное влияние за «влияние» (ресурс кардинала, восстанавливается со временем):
- 😠 Поссорить — настраивает выбранного против другого
- 🕊️ Помирить — чинит отношения
- 💰 Подкупить — деньги за лояльность
- 😨 Запугать — проверка воли (GURPS), жертва пугается
- 🕵️ Подставить — пишет донос инквизиции

**Приказы** — прямые команды:
- 🚶 Идти (клик по месту), 👣 Следовать, ⚔️ Атаковать, 🛒 Торговать, ⏸️ Ждать, 🆓 Отпустить

## 🗺️ Разрушаемая карта

Город собран из тайлов: стены, полы, двери, кровати. У каждого тайла — материал и прочность:
- 🪵 **Дерево** (стены, полы, двери, кровати) — **горит**
- 🌿 **Трава** — тоже горит и расползается огнём
- 🪨 **Камень** — не горит, но прочный

После догорания стена/пол/трава превращаются в **грязь**. Под дверями и кроватями всегда лежит пол — когда дверь или кровать сгорает, пол остаётся.

Огонь распространяется по соседним горючим тайлам. NPC ходят по A\*-путям, **открывают двери** при подходе, видят друг друга только в прямой видимости (стены блокируют взгляд), а свидетелями преступлений становятся лишь те, кто реально видел.

**Кровати** — у каждого NPC своя: на ночь куклы уходят спать в свою кровать.

## 🧥 Гардероб (три куртки)

- 👑 **lord_coat_body** — куртка лорда, перекрашивается в **кроваво-красный** (#8B0000)
- 🔥 **inquisition_coat** — куртка инквизитора, **тёмно-серая** (#555555)
- 🧍 **coat_body** — обычная куртка, перекрашивается по роли:
  - Жители → #556B2F
  - Стража → #2F4F4F
  - Епископ → чёрный

## 🛒 Еда и торговля

Еды у жителей нет со старта — все просыпаются голодными. Когда голод падает, NPC идёт в лавку к торговцу, покупает еду (💰 за 🍞) и ест. Деньги жители зарабатывают ежедневной работой.

## 👥 Роли

- 👑 **Барон** — правитель в замке (его смерть = анархия)
- ⛪ **Епископ** — держит порядок и веру
- 🔥 **Инквизитор** — охотится на еретиков, читает доносы
- 💰 **Казначей** — казна (иногда коррумпирован)
- ⚔️ **Гарнизон** — патрулирует и арестовывает
- 🛒 **Торговец** — продаёт еду
- 👤 **Жители** — работают, общаются, воруют, влюбляются

## 📁 Структура

```
assets/sprites/       # тайлы и куклы (сейчас — плейсхолдеры, замени своими PNG)
scenes/
├── main.tscn         # город: карта, камера, HUD
└── characters/npc.tscn
scripts/
├── autoload/         # game_manager, time_system, save_system
├── characters/
│   ├── base_npc.gd   # кукла-актёр (зрение, еда, приказы)
│   ├── ai/           # потребности, отношения, память, состояния, GURPS, убийства…
│   └── roles/        # роли NPC
├── world/
│   ├── world_map.gd  # тайлы, разрушение, огонь, A*
│   ├── camera_controller.gd
│   └── city.gd
└── ui/
    ├── gray_cardinal.gd  # панель «ниточек»
    ├── hud.gd, dialog_system.gd, relationship_map.gd
```

## 🖼️ Свои спрайты

Положи свои PNG в `assets/sprites/` с теми же именами:
`grass`, `dirt`, `wood_floor`, `stone_floor`, `wood_wall`, `stone_wall`, `door_closed`, `door_opened`, `bed`, `fire`, `head`, `coat_body`, `lord_coat_body`, `inquisition_coat`.

Размер тайла **64×64** (уточняется автоматически по `grass.png`). Куклы, коллизии, скорость NPC, камера и подбор кликов подстраиваются под него. Все тайлы должны быть 64×64.

## 🔧 Запуск

1. Установи [Godot 4.3+](https://godotengine.org/) (проект собран под 4.7)
2. Открой проект (спрайты импортируются автоматически)
3. **Run** (F5)

Удачной пьесы! 🎭
