# 🟢 Шариковая Жизнь (Ball Life)

2D симуляция жизни с интеллектуальными NPC. Жители работают, общаются, влюбляются... и ненавидят.

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **ЛКМ** | Диалог с NPC |
| **ПКМ** | Пауза |
| **M** | Карта отношений |
| **F5** | Сохранить |
| **F6** | Загрузить |
| **R** | Новая игра |
| **ESC** | Пауза |

## 🎯 Цель игры

Наблюдай за жизнью шариков-горожан. Они работают, общаются, влюбляются... и ненавидят. Иногда ненависть перерастает в нечто большее.

## 👥 Роли

### 🏛️ Мэр
- Контролирует городскую казну
- Получает налоги
- **Убийство мэра = АНАРХИЯ**

### ⭐ Шериф
- Патрулирует ночью
- Расследует преступления
- Арестовывает и наказывает

### 👤 Жители
- **Работяги** — честно трудятся
- **Воры** (30%) — крадут ночью
- Могут планировать убийства

## 🩸 Система убийств

1. **Накопление ненависти** — оскорбления, кражи
2. **Планирование** — readiness растёт, появляется план
3. **Попытка** — обычно ночью, шанс успеха зависит от улик
4. **Расследование** — шериф ищет доказательства
5. **Правосудие** — при evidence >= 85% убийца наказан

## 🎪 Динамические события

- **🎉 Праздник** — все общаются
- **💰 День налогов** — мэр собирает налоги
- **📢 Собрание** — жители обсуждают проблемы
- **⚠️ Бунт** — при низком порядке
- **⚔️ Анархия** — если мэр убит

## 📊 Интерфейс

- **Клик на NPC** — диалог (можно оскорбить/подружиться)
- **Журнал событий** (справа) — последние события
- **Карта отношений** (M) — визуализация связей
- **Индикатор порядка** — стабильность города

## 💾 Сохранение

- F5 — сохранить
- F6 — загрузить
- Автосохранение (future)

## 🔧 Установка

1. Установи [Godot 4.x](https://godotengine.org/)
2. Импортируй проект
3. Нажми **Run** (F5)
